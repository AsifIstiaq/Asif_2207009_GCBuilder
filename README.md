GPA Builder

A simple JavaFX application for adding courses, calculating GPA, and saving results.

Features

1) Add, update, and delete course information

2) Autoload the last added course when the app starts

3) Calculate GPA based on all added courses

4) Save GPA results (total credits, GPA, required credits, course list)

5) Show the last saved GPA result when opening the Result page

6) Export GPA report

7) Clean and simple GUI built using JavaFX

8) SQLite database support
